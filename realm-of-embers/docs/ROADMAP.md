# 《王国余烬》开发路线图

> 最后更新：v0.4a 后 · 本文件是唯一权威排期来源，做完一项勾一项。
>
> **设计基调（必须遵守）**
> 1. 借成熟玩法的"神"（主动决策、驻军阻挡、星级目标），不抄"形"（固定战役/数值结构）；
> 2. 新机制优先复用已验证模式（KR/杀戮尖塔类），自创玩法必须先过"玩家 30 秒能懂"门槛；
> 3. 一切数值进 `data/*.json`，一切表现走烘焙管线，测试走 `--autotest / --testload / --skilltest`。

## v0.4b 多地图 × 三星 × 三难度（预估 3~5 天）

| 任务 | 内容 | 依赖 | 验收 |
|---|---|---|---|
| `data/maps.json` | id/名称/路径/塔位/城堡位/地面色板/波次表引用；DataLoader 扩展按图加载 | 无 | 三张图可独立加载 |
| 三张图 | ①王都大道（现图）②峡谷关隘（双入口交汇）③断桥要塞（短路径高密度，Boss Rush） | maps.json | 各图手写 `waves_<id>.json`，难度曲线独立 |
| 三星评价 | ★1 通关 / ★2 耐久≥50% / ★3 耐久≥90%；`user://stars.json` 持久化；★数解锁下一图 | maps.json | 选关页显示星级，锁定态可见 |
| 三档难度 | 休闲(敌血×0.8 初始金+40)/标准/严酷(×1.3 利息减半)；难度乘数进 rules.json | maps.json | 严酷明显更难，休闲可保底 |
| 选关 UI | 主菜单"开始"→地图卡片页（星级/难度/最佳波数） | 三星 | 触屏可点 |

## v0.4c 无尽 + 每日（预估 2~3 天）

| 任务 | 内容 | 验收 |
|---|---|---|
| 无尽模式 | 15 波后波次生成器接管：按"预算递增"混编敌人（预算=基础×1.12^波），每 5 波一个 Boss；本地最高波数记录 | 撑过 25 波不出重复感 |

| 结算增强 | 局末统计：总击杀/技能使用次数/最高连击，写入分享码 | — |

## 技术债与风险

| 项 | 风险 | 处理时机 |
|---|---|---|
| main.gd 900+ 行 | 每次改动回归成本升高 | **v0.5 动英雄前必须先拆** |
| gh-pages 旧版 | 分享出去的链接是旧玩法 | v0.6 与 itch 一起做 |
| 平衡数据空白 | 数值全凭手感 | v0.6 批量跑局脚本 |
| 触屏实机未测 | 安卓/手机浏览器未知 | v0.6 Web 导出后 |
| 音量平衡未调 | 部分音效可能过吵 | 收到反馈即调（sfx_bank.gd 限流表+音量表集中管理） |
