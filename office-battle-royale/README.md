# 职场大逃杀（原型）

职场升职肉鸽卡牌 · Godot 4 · 单机 · 单局 8~15 分钟 · 单场景纯 UI/Emoji，零原画

## 运行

1. 安装 **Godot 4.2+**（推荐 4.3+，中文/Emoji 依赖系统字体回退）。
2. Godot → Import → 选择本目录的 `project.godot` → F5。无菜单，直接进节点 1「临时需求」。

## 玩法速览

- **精力 80** = 生命值，归零失败；**压力 0~100** = 第二失败条，满 100 失败；
- 每回合 **3 行动点**、抽 5 张牌，回合结束弃掉剩余手牌；牌库抽空时弃牌堆洗回；
- **工作量** = 敌人血量，降到 0 完成该节点；**护盾只挡精力伤害，不挡压力**；
- 敌人按 `intents` 轮转出招（面板实时显示本回合意图）；
- 节点胜利回复 8 精力、压力 -8；**3/6/9 节点后三选一加卡**；12 节点后击败「老板终面」获胜；
- 失败/胜利后空格或按钮重开。

## 改数值 = 改玩法（data/）

| 文件 | 内容 | 关键字段 |
|---|---|---|
| `data/cards.json` | 20 张卡池 | `cost` / `type` / `rarity` / `effects`（progress/block/heal/stress/draw/energy） |
| `data/enemies.json` | 10 个敌人 | `hp` / `intents`（damage/stress 轮转） |
| `data/nodes.json` | 12 节点编排 | `enemy` / `hpMul` / `mul`（伤害与压力统一倍率）/ `suffix`（“加强”显示名） |

节点 10/11 即“线上故障·加强 / 竞品突袭·加强”：复用敌人定义，`hpMul/mul = 1.3` 数值放大，改表即可调难度曲线。

## 结构

```
res://
├─ scenes/Main.tscn   # 单场景：顶栏状态 + 敌人面板 + 手牌流式布局 + 奖励/结算浮层
├─ scripts/main.gd    # 全部战斗逻辑（出牌/结算/抽洗/节点与奖励流程）
└─ data/              # cards.json enemies.json nodes.json
```

已知扩展位（原型刻意不做）：卡牌升级、删卡、遗物、存档、动画音效。
